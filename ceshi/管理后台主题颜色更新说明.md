## 六、主题特点

### 明亮主题特点
1. 🎨 **温暖色调**：使用橙色作为主色，给人温暖、活力的感觉
2. 🌟 **高对比度**：米白色背景搭配深棕色文字，阅读体验佳
3. ✨ **现代简约**：浅色背景，简洁清爽
4. 🔵 **蓝色点缀**：使用蓝色作为强调色，增加视觉层次

### 暗色主题特点
1. 🌙 **护眼设计**：深色背景降低屏幕亮度
2. 🎨 **保持一致**：主色和强调色与明亮主题保持一致
3. ⚡ **高级感**：深色调营造专业、高端的视觉效果
4. 🔆 **适度对比**：避免纯黑背景，使用深棕色更柔和

## 九、如何切换主题

### 方法1：在根元素添加 dark 类
```html
<html class="dark">
  <!-- 暗色主题 -->
</html>
```

### 方法2：通过 JavaScript 动态切换
```javascript
// 切换到暗色主题
document.documentElement.classList.add('dark')

// 切换到明亮主题
document.documentElement.classList.remove('dark')

// 切换主题
document.documentElement.classList.toggle('dark')
```

### 方法3：根据系统偏好自动切换
```javascript
if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
  document.documentElement.classList.add('dark')
}
```

## 十五、常见问题

### Q1: 为什么某些页面颜色没有变化？
**A:** 可能原因：
1. 页面使用了内联样式（inline styles）
2. 页面有更高优先级的 CSS 规则
3. 页面使用了固定的颜色值而非 CSS 变量
4. 需要清除浏览器缓存

**解决方法**：
- 使用浏览器开发工具检查元素的实际应用样式
- 确保页面使用了 CSS 变量而非硬编码颜色
- 清除浏览器缓存并强制刷新（Ctrl+Shift+R）

### Q2: 如何自定义主题颜色？
**A:** 修改 `src/app/globals.css` 文件中的 CSS 变量值：
```css
:root {
  --primary: #你的颜色; /* 修改主色调 */
  --accent: #你的颜色;  /* 修改强调色 */
  /* ... */
}
```

### Q3: 暗色主题如何自动启用？
**A:** 可以在布局组件中添加逻辑：
```typescript
useEffect(() => {
  const isDark = localStorage.getItem('theme') === 'dark' ||
    window.matchMedia('(prefers-color-scheme: dark)').matches
  
  if (isDark) {
    document.documentElement.classList.add('dark')
  }
}, [])
```

### Q4: 某些组件颜色显示不正确？
**A:** 检查组件是否使用了：
1. 固定的 Tailwind 类名（如 `bg-blue-500` 而非 `bg-primary`）
2. 内联样式（`style={{ color: '#000' }}`）
3. 独立的 CSS 文件

需要修改为使用 CSS 变量或主题相关的 Tailwind 类。

### Q5: 如何为特定页面使用不同主题？
**A:** 在页面组件中动态添加类名：
```typescript
export default function MyPage() {
  useEffect(() => {
    document.documentElement.classList.add('dark')
    return () => {
      document.documentElement.classList.remove('dark')
    }
  }, [])
  
  return <div>页面内容</div>
}
```
