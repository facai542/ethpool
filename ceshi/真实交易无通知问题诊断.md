**根本原因**：Moralis Webhook 没有推送真实交易数据到服务器

## 可能的原因

### 1. Moralis Stream 配置缺失

**问题**：Stream 可能没有正确配置监听 USDT Transfer 事件

**检查方法**：
1. 访问 https://admin.moralis.io/streams
2. 找到 Stream: eth-usdt-monitor
3. 查看 "ABI" 和 "Filters" 配置

**应该包含**：
- Contract Address: 0xdAC17F958D2ee523a2206206994597C13D831ec7
- Event: Transfer(address,address,uint256)
- Topic0: Transfer 事件签名

### 2. 交易确认数不够

**问题**：Moralis 默认需要 12 个区块确认才推送

**时间**：以太坊 12 区块 ≈ 2.4 分钟

**解决方法**：
```javascript
// 在创建 Stream 时设置
await Moralis.Streams.update({
  id: STREAM_ID,
  confirmationsRequired: 1  // 降低到 1 个确认
})
```

### 3. Webhook URL 配置错误

**当前配置**：https://ethmax.vercel.app/api/moralis/webhook

**可能问题**：
- 域名可能不是当前部署的域名
- API 路由可能未部署到生产环境

**检查 Vercel 实际域名**：
1. 访问 https://vercel.com/项目
2. 查看 "Domains" 配置
3. 确认实际访问域名

### 4. Stream 没有正确创建

**问题**：Stream 可能缺少关键配置

**完整配置应该包含**：
```javascript
{
  chains: ['0x1'],  // Ethereum Mainnet
  description: 'ETH USDT Transaction Monitor',
  tag: 'eth-usdt-monitor',
  webhookUrl: 'https://实际域名.vercel.app/api/moralis/webhook',
  includeNativeTxs: false,
  includeContractLogs: true,
  allAddresses: false,  // 不监听所有地址
  topic0: ['Transfer(address,address,uint256)'],
  advancedOptions: [{
    topic0: 'Transfer(address,address,uint256)',
    filter: { 
      eq: ['address', '0xdAC17F958D2ee523a2206206994597C13D831ec7'] 
    }
  }],
  abi: [{
    anonymous: false,
    inputs: [
      { indexed: true, name: 'from', type: 'address' },
      { indexed: true, name: 'to', type: 'address' },
      { indexed: false, name: 'value', type: 'uint256' }
    ],
    name: 'Transfer',
    type: 'event'
  }]
}
```

## 最可能的问题

根据经验，最可能的问题是：

### 问题1：Webhook URL 域名不对

**症状**：Moralis 推送但服务器收不到

**原因**：
- Vercel 项目有多个域名
- Stream 配置的域名和实际不一致

**解决**：
1. 访问 Vercel Dashboard
2. 查看项目的实际域名
3. 更新 Moralis Stream Webhook URL

### 问题2：Stream 未配置 USDT 合约

**症状**：地址添加成功但没有事件

**原因**：Stream 可能只监听地址，没有监听 USDT 合约

**解决**：重新创建 Stream，明确配置 USDT 合约和 Transfer 事件

### 问题3：confirmationsRequired 太高

**症状**：交易确认后很久才收到通知

**原因**：默认 12 个确认 ≈ 2.4 分钟

**解决**：
```javascript
await Moralis.Streams.update({
  id: STREAM_ID,
  confirmationsRequired: 1  // 降低到 1 个确认
})
```
