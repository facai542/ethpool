# Supabase 数据库导出指南

## 方法1：导出特定表（通过 SQL）

在 Supabase SQL Editor 中执行：

```sql
-- 查看所有表
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
ORDER BY table_name;

-- 导出特定表为 CSV
COPY (SELECT * FROM wallet_transactions) TO STDOUT WITH CSV HEADER;
COPY (SELECT * FROM telegram_notification_queue) TO STDOUT WITH CSV HEADER;
COPY (SELECT * FROM wallet_monitor) TO STDOUT WITH CSV HEADER;
COPY (SELECT * FROM nh_member_new) TO STDOUT WITH CSV HEADER;
```

## 方法2：使用 pg_dump（导出整个数据库）

### 步骤1：获取数据库连接信息

1. 打开 Supabase Dashboard
2. 进入 Settings → Database
3. 找到 Connection String（Direct Connection）
   格式：`postgresql://postgres.[project-ref]:[password]@aws-0-[region].pooler.supabase.com:6543/postgres`

### 步骤2：执行导出命令

**Windows PowerShell：**
```powershell
# 导出整个数据库（包括结构和数据）
pg_dump "postgresql://postgres.fkbuzpptiyxphlbjijwn:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:6543/postgres" > supabase_backup.sql

# 仅导出数据（不包括结构）
pg_dump --data-only "postgresql://postgres.fkbuzpptiyxphlbjijwn:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:6543/postgres" > supabase_data.sql

# 导出特定表
pg_dump -t wallet_transactions -t telegram_notification_queue "postgresql://..." > tables_backup.sql
```

**如果没有 pg_dump，安装 PostgreSQL 客户端工具：**
```powershell
# 使用 Chocolatey 安装
choco install postgresql

# 或下载安装包
# https://www.postgresql.org/download/windows/
```

## 方法3：通过 Supabase CLI

```bash
# 登录 Supabase
supabase login

# 导出数据库
supabase db dump --db-url "postgresql://..." > backup.sql

# 导出特定表
supabase db dump --db-url "postgresql://..." -t wallet_transactions > table.sql
```

## 方法4：导出为 JSON（通过 API）

在项目中创建一个简单的导出脚本：

```javascript
import { createClient } from '@supabase/supabase-js'
import fs from 'fs'

const supabase = createClient(
  'YOUR_SUPABASE_URL',
  'YOUR_SERVICE_ROLE_KEY' // 使用 service_role_key
)

async function exportTable(tableName) {
  const { data, error } = await supabase
    .from(tableName)
    .select('*')
  
  if (error) {
    console.error('导出失败:', error)
    return
  }
  
  fs.writeFileSync(
    `${tableName}_export.json`,
    JSON.stringify(data, null, 2)
  )
  
  console.log(`✅ ${tableName} 已导出 (${data.length} 条记录)`)
}

// 导出多个表
await exportTable('wallet_transactions')
await exportTable('telegram_notification_queue')
await exportTable('wallet_monitor')
```

## 推荐方案

**快速查看数据：** 使用方法1（SQL COPY）
**完整备份：** 使用方法2（pg_dump）
**自动化脚本：** 使用方法4（API + JSON）
