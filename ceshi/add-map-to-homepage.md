## MapDemo 组件特性

### 🌍 地图功能
- **世界地图**: 使用DottedMap生成点状世界地图
- **连接线**: 显示全球挖矿节点之间的连接
- **动画效果**: 连接线动态绘制动画
- **主题适配**: 支持明暗主题切换

### 📍 挖矿节点
组件显示6个全球挖矿节点连接：
1. **北京** ↔ **纽约**
2. **东京** ↔ **伦敦**  
3. **新加坡** ↔ **悉尼**
4. **迪拜** ↔ **柏林**
5. **圣保罗** ↔ **旧金山**
6. **墨西哥城** ↔ **莫斯科**

### 🎨 视觉设计
- **标题**: "全球挖矿网络" (黄色渐变)
- **描述**: 网络介绍文字
- **地图**: 点状世界地图背景
- **连接线**: 黄色发光连接线
- **动画**: 3秒循环动画

## 技术实现

### 依赖组件
- **WorldMap**: 核心地图渲染组件
- **DottedMap**: 点状地图生成库
- **Framer Motion**: 动画效果
- **useI18n**: 国际化支持

### 动画配置
```tsx
<WorldMap
  dots={[...6个节点连接]}
  lineColor="#F59E0B"    // 黄色连接线
  showLabels={true}      // 显示城市标签
  animationDuration={3}  // 3秒动画时长
  loop={true}           // 循环播放
/>
```

- **移动端**: 自适应宽度，合适的字体大小
- **桌面端**: 最大7xl宽度居中显示
- **动画**: 所有设备上流畅运行
