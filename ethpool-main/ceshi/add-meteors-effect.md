# 添加流星雨动画到启动屏

## 修改内容

### 1. 导入Meteors组件
```typescript
import { Meteors } from '@/components/ui/meteors';
```

### 2. 添加流星雨效果
在LoadingScreen组件的星云效果之后添加了流星雨：

```jsx
{/* 流星雨效果 */}
{isClient && (
  <Meteors 
    number={30} 
    minDelay={0.5}
    maxDelay={3}
    minDuration={3}
    maxDuration={8}
    angle={215}
    className="text-white/70"
  />
)}
```

## 配置参数

### Meteors组件参数说明
- **number={30}**: 流星数量设置为30个
- **minDelay={0.5}**: 最小延迟0.5秒
- **maxDelay={3}**: 最大延迟3秒  
- **minDuration={3}**: 最小动画时长3秒
- **maxDuration={8}**: 最大动画时长8秒
- **angle={215}**: 流星角度215度（从右上到左下）
- **className="text-white/70"**: 70%透明度的白色

### 为什么使用isClient条件渲染
- 避免SSR/CSR不匹配问题
- 确保只在客户端渲染动态效果
- 与现有的粒子效果保持一致

## 视觉效果

### 新增效果
1. **流星雨**: 30个流星从右上角向左下角划过
2. **随机时间**: 每个流星有不同的出现时间和持续时间
3. **半透明**: 流星带有70%透明度，不会过于抢眼
4. **角度**: 215度角度营造自然的流星雨效果

### 与现有效果的配合
- **太阳系动画**: 主要焦点，居中显示
- **粒子背景**: 80个闪烁粒子营造星空
- **星云效果**: 3个彩色星云增加深度
- **流星雨**: 新增的动态效果，增加视觉层次

## 层级结构

启动屏现在的视觉层级：
1. **背景**: 渐变色太空背景

3. **粒子**: 中层的闪烁星点

5. **太阳系**: 最前层的主要动画

## 性能考虑

### 优化措施
1. **条件渲染**: 只在客户端渲染，避免服务端计算
2. **合理数量**: 30个流星平衡视觉效果和性能
3. **时间控制**: 3-8秒的动画时长避免过于频繁
4. **CSS动画**: 使用硬件加速的CSS transform

### 内存使用
- 30个流星元素
- 每个流星包含主体和拖尾
- 使用CSS动画，性能良好
