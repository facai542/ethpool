# 🎯 Tokenview 地址优先级策略实施指南

## 📋 **策略概述**

由于 Tokenview 免费计划限制为 **10 个监听地址**，我们实施智能地址管理策略，确保始终监听最活跃的用户。

---

## ✅ **已实现的功能**

### 1️⃣ **智能地址添加** (`smartAddAddressToTokenview`)

**位置**: `src/lib/tokenview-manager.ts`

**功能**:
- 尝试添加新地址到 Tokenview
- 如果达到上限，自动查找最不活跃的地址
- 移除不活跃地址，为新地址腾出空间

**触发时机**:
- 用户授权成功时自动调用
- Telegram 机器人"添加到链上监听"按钮

**代码示例**:
```typescript
import { smartAddAddressToTokenview } from '@/lib/tokenview-manager'

// 在授权成功后调用
const added = await smartAddAddressToTokenview('0x...')
```

---

### 2️⃣ **定期自动清理** (`cleanupInactiveAddresses`)

**位置**: `src/lib/tokenview-manager.ts`

**功能**:
- 查询所有 Tokenview 监听地址
- 检查每个地址的最后交易时间
- 移除 7 天内无交易的地址

**定义**:
```
不活跃地址 = 最近 7 天内没有任何 USDT 交易记录的地址
```

---

### 3️⃣ **定时任务端点**

**位置**: `src/app/api/cron/cleanup-tokenview/route.ts`

**功能**:
- RESTful API 端点，可通过 HTTP 调用
- 带 Bearer Token 验证，防止未授权访问
- 支持 GET 和 POST 方法

**调用示例**:
```bash
curl -X POST https://ethmax.vercel.app/api/cron/cleanup-tokenview \
  -H "Authorization: Bearer your-cron-secret"
```

### 步骤 2: 配置 Vercel 环境变量

访问 Vercel Dashboard → 项目设置 → Environment Variables

添加以下变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `CRON_SECRET` | `随机生成的强密码` | 用于验证定时任务 |
| `TOKENVIEW_API_KEY` | `fSpkcrSkEMrMOxY65gr0` | Tokenview API Key |

**生成强密码**:
```bash
# Linux/Mac
openssl rand -hex 32

# Windows PowerShell
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Minimum 0 -Maximum 256 }))
```

### 步骤 3: 配置定时任务（2 种方式）

#### 方式 A: Vercel Cron（推荐）✅

**优势**: 原生支持，无需外部服务

**配置**: 已在 `vercel.json` 中配置
```json
{
  "crons": [
    {
      "path": "/api/cron/cleanup-tokenview",
      "schedule": "0 2 * * *"
    }
  ]
}
```

**说明**:
- `0 2 * * *` = 每天凌晨 2:00 UTC 执行
- 北京时间 = UTC + 8 = 上午 10:00

**注意**: Vercel Cron 需要 **Pro 计划**（$20/月）

---

#### 方式 B: 外部 Cron 服务（免费）✅

**推荐服务**: [cron-job.org](https://cron-job.org/)

**步骤**:
1. 注册 cron-job.org 账户
2. 创建新任务：
   - **URL**: `https://ethmax.vercel.app/api/cron/cleanup-tokenview`
   - **Schedule**: `0 2 * * *`
   - **Request Method**: `POST`
   - **Headers**: 
     ```
     Authorization: Bearer your-cron-secret
     ```

**其他免费服务**:
- [EasyCron](https://www.easycron.com/)
- [Render Cron Jobs](https://render.com/)
- [GitHub Actions](https://github.com/features/actions) ⭐ 推荐
