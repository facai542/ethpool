## 第二步：配置定时任务（5 分钟）⏰

### 推荐：使用 cron-job.org（完全免费）

---

### 2.1 注册 cron-job.org

**访问**:
```
https://console.cron-job.org/signup
```

**填写信息**:
- Email: 您的邮箱
- Password: 设置密码
- ☑ 勾选 "I accept the Terms of Service"
- 点击 **Sign up**

**验证邮箱**:
- 打开邮箱
- 点击验证链接

---

### 2.2 创建定时任务

登录后，点击 **Create cronjob** 按钮

**填写表单**:

#### ① 基本信息

```
Title: Tokenview 地址清理
```

#### ② URL 设置

```
Address (URL): https://ethmax.vercel.app/api/cron/cleanup-tokenview
Request method: POST ▼
Request timeout: 30 seconds
```

#### ③ Headers（重要！）

点击 **Headers** 标签，添加：

```
Key:   Authorization
Value: Bearer eb904580cc0abe1d53f08f24773311a29d4141e845058c01f4d86c553cd925cf
```

⚠️ **注意**: 
- `Bearer` 后面有一个空格
- 完整复制粘贴密钥

#### ④ Schedule（时间设置）

点击 **Schedule** 标签：

```
Pattern: Custom ▼

Minutes:  0  (每小时的第 0 分钟)
Hours:    2  (凌晨 2 点)
Days:     *  (每天)
Months:   *  (每月)
Weekdays: *  (每周)
```

**Cron 表达式**: `0 2 * * *`

**说明**: 每天凌晨 2:00 UTC 执行（北京时间 10:00）

#### ⑤ 通知设置

```
☑ Email notifications on failure
☑ Enable job
```

#### ⑥ 保存

点击底部 **Create cronjob** 按钮

---

## ⚠️ 常见问题

### Q: 定时任务返回 401 错误？

**检查**:
- cron-job.org 的 Authorization Header 是否正确
- 格式是否为 `Bearer <密钥>`（注意空格）
- Vercel CRON_SECRET 环境变量是否已配置

**解决**:
1. 重新检查 Header 配置
2. 重新保存任务
3. 手动测试

---

### Q: Vercel 日志没有清理记录？

**原因**: 
- 定时任务尚未触发（等待明天 2:00）
- 手动测试未成功

**解决**:
1. 在 cron-job.org 手动触发（点击 ▶ 按钮）
2. 立即查看 Vercel 日志
3. 如果还是没有，检查 Vercel 环境变量

---

### Q: 新用户授权后没有添加到 Tokenview？

**检查**:
1. Vercel 环境变量 `TOKENVIEW_API_KEY` 是否配置
2. 查看授权日志：搜索 "智能添加地址"
3. Tokenview 是否已有 10 个地址（已满）

**解决**:
```bash
# 手动清理一次
curl -X POST https://ethmax.vercel.app/api/cron/cleanup-tokenview \
  -H "Authorization: Bearer eb904580cc0abe1d53f08f24773311a29d4141e845058c01f4d86c553cd925cf"

# 然后重新授权测试
```
