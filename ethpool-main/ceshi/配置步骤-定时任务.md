# 定时任务配置步骤

## 🎯 **推荐方案：使用 cron-job.org**

**优势**:
- ✅ 完全免费
- ✅ 无需信用卡
- ✅ Web 界面简单
- ✅ 支持实时日志
- ✅ 邮件通知失败

---

## 📋 **完整配置步骤（5 分钟）**

### 步骤 1: 注册账户（2 分钟）

1. **访问注册页面**:
   ```
   https://console.cron-job.org/signup
   ```

2. **填写信息**:
   - Email: 您的邮箱
   - Password: 设置密码
   - 勾选 "I accept the Terms of Service"

3. **验证邮箱**:
   - 打开邮箱，查收验证邮件
   - 点击验证链接

4. **登录**:
   ```
   https://console.cron-job.org/login
   ```

---

### 步骤 2: 创建定时任务（3 分钟）

#### 2.1 创建新任务

登录后，点击 **"Create cronjob"** 按钮

#### 2.2 填写任务信息

**基础设置**:

| 字段 | 值 | 说明 |
|------|-----|------|
| **Title** | `Tokenview 地址清理` | 任务名称 |
| **Address (URL)** | `https://ethmax.vercel.app/api/cron/cleanup-tokenview` | API 端点 |

**请求设置**:

| 字段 | 值 | 说明 |
|------|-----|------|
| **Request method** | `POST` | 请求方法 |
| **Request timeout** | `30 seconds` | 超时时间 |

**认证设置**:

点击 **"Headers"** 标签，添加：

| Key | Value |
|-----|-------|
| `Authorization` | `Bearer eb904580cc0abe1d53f08f24773311a29d4141e845058c01f4d86c553cd925cf` |

**⚠️ 重要**: 
- 格式必须是 `Bearer <你的密钥>`
- 注意 `Bearer` 后面有一个空格

**时间设置**:

点击 **"Schedule"** 标签：

| 选项 | 值 |
|------|-----|
| **Pattern** | `Custom` |
| **Minute** | `0` |
| **Hour** | `2` |
| **Day** | `*` (Every) |
| **Month** | `*` (Every) |
| **Weekday** | `*` (Every) |

**Cron 表达式**: `0 2 * * *`

**说明**: 每天凌晨 2:00 UTC 执行（北京时间 10:00）

**通知设置**:

勾选以下选项：
- ✅ **Email notifications on failure** (失败时邮件通知)
- ✅ **Enable job** (启用任务)

#### 2.3 保存任务

点击 **"Create cronjob"** 按钮保存

1. 找到刚创建的任务

## 🔄 **其他方案（可选）**

### 方案 2: GitHub Actions（免费）

**优势**:
- ✅ 完全免费
- ✅ 与代码仓库集成
- ✅ 支持手动触发

**步骤**:

1. **创建 workflow 文件**:

在本地项目运行：

```bash
mkdir -p .github/workflows
```

创建文件 `.github/workflows/cleanup-tokenview.yml`:

```yaml
name: Tokenview 地址清理

on:
  schedule:
    # 每天 2:00 UTC (北京时间 10:00)
    - cron: '0 2 * * *'
  
  # 允许手动触发
  workflow_dispatch:

jobs:
  cleanup:
    runs-on: ubuntu-latest
    
    steps:
      - name: 触发清理 API
        run: |
          curl -X POST https://ethmax.vercel.app/api/cron/cleanup-tokenview \
            -H "Authorization: Bearer ${{ secrets.CRON_SECRET }}" \
            -f || exit 1
      
      - name: 记录结果
        if: always()
        run: echo "清理任务已执行"
```

2. **添加 GitHub Secret**:

访问 GitHub 仓库设置：
```
https://github.com/facai1422/eth/settings/secrets/actions
```

- 点击 **"New repository secret"**
- Name: `CRON_SECRET`
- Value: `eb904580cc0abe1d53f08f24773311a29d4141e845058c01f4d86c553cd925cf`
- 点击 **"Add secret"**

3. **推送到 GitHub**:

```bash
git add .github/workflows/cleanup-tokenview.yml
git commit -m "添加 GitHub Actions 定时清理任务"
git push
```

4. **手动测试**:

- 访问 GitHub 仓库的 **Actions** 标签
- 选择 **"Tokenview 地址清理"** workflow
- 点击 **"Run workflow"** → **"Run workflow"**
- 查看执行结果

## ⚠️ **常见问题**

### Q1: 任务执行失败，返回 401？

**原因**: Authorization header 配置错误

**检查**:
- Header Key 是否为 `Authorization`
- Value 格式是否为 `Bearer <密钥>`
- 密钥是否与 Vercel 环境变量一致

**解决**:
```bash
# 重新生成密钥
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 1. 更新 Vercel 环境变量
# 2. 更新 cron-job.org Header
# 3. 重新部署 Vercel
```

### Q2: 任务执行失败，返回 500？

**原因**: Tokenview API 或数据库错误

**检查**:
1. 查看 Vercel 日志详细错误
2. 确认 TOKENVIEW_API_KEY 是否有效
3. 确认数据库连接正常

**解决**:
```bash
# 手动测试
curl -X POST https://ethmax.vercel.app/api/cron/cleanup-tokenview \
  -H "Authorization: Bearer <你的密钥>" \
  -v
```

### Q3: 任务没有按时执行？

**原因**: cron-job.org 可能延迟

**检查**:
- cron-job.org 任务是否启用（Enabled）
- Schedule 设置是否正确
- 账户是否被暂停

**解决**:
- 手动触发测试
- 检查邮箱是否有通知
- 联系 cron-job.org 支持
