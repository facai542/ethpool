# 用户授权后未添加到实时监控 - 诊断和修复指南

## 🔍 问题诊断

### 步骤 1：运行诊断接口

访问以下 URL 检查系统配置：

```
https://你的域名/api/debug/check-monitor-setup
```

这将返回完整的系统诊断报告，包括：
- ✅ 环境变量配置
- ✅ 数据库表状态
- ✅ Moralis Stream 配置
- ✅ 发现的问题和修复建议

### 步骤 2：检查 Vercel 日志

1. 访问 Vercel Dashboard
2. 选择你的项目
3. 点击 **Functions** 标签
4. 找到 `/api/user/authorize` 函数
5. 查看最近的调用日志

**关键日志标记：**
```
🔑 处理授权请求
🔍 授权条件检查
✅ 进入授权成功处理流程
🔍 添加地址到Telegram动账监听系统
🔍 添加地址到 Moralis Stream 链上监听
```

如果看到：
- ✅ `添加地址到Telegram动账监听系统` → 说明进入了监听添加流程
- ❌ 没有这条日志 → 说明授权条件判断失败

### 步骤 3：检查数据库

在 Supabase SQL Editor 中运行：

```sql
-- 1. 检查最近授权的用户
SELECT 
  id, 
  wallet_address, 
  approved, 
  first_approved_at,
  created_at
FROM nh_member_new
WHERE approved = 1
ORDER BY first_approved_at DESC
LIMIT 10;

-- 2. 检查监听列表
SELECT 
  id,
  wallet_address,
  is_active,
  monitor_transactions,
  created_at
FROM wallet_monitor
WHERE is_active = true
ORDER BY created_at DESC
LIMIT 10;

-- 3. 检查未发送的通知
SELECT 
  id,
  notification_type,
  user_id,
  is_sent,
  created_at,
  error_message
FROM telegram_notification_queue
WHERE is_sent = false
ORDER BY created_at DESC
LIMIT 10;

-- 4. 检查最近的 USDT 交易记录
SELECT 
  id,
  user_address,
  transaction_type,
  amount,
  tx_hash,
  is_processed,
  created_at
FROM wallet_transactions
ORDER BY created_at DESC
LIMIT 10;
```

## 🛠️ 常见问题和解决方案

### 问题 1: 环境变量未在 Vercel 生效

**症状：**
- 诊断显示环境变量为 `false`
- 日志显示变量为 `undefined`

**解决方法：**

1. **在 Vercel Dashboard 添加环境变量**

   访问：`https://vercel.com/你的项目/settings/environment-variables`

   添加以下变量（**所有环境**都要勾选）：

   ```
   TELEGRAM_BOT_TOKEN=8244139410:AAECUajPMdPx4C6b64YO0Wu2ginswejST_I
   TELEGRAM_CHAT_ID=-1003149735777
   MORALIS_API_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...（你的密钥）
   NEXT_PUBLIC_APP_URL=https://你的域名.vercel.app
   ```

   ⚠️ **重要**：
   - `TELEGRAM_CHAT_ID` 前面有负号 `-`
   - `NEXT_PUBLIC_APP_URL` 必须是完整的 URL（包括 `https://`）
   - 所有环境（Production, Preview, Development）都要勾选

2. **重新部署**

   ```bash
   # 方式 1：在 Vercel Dashboard
   Deployments → 最新部署 → ••• → Redeploy

   # 方式 2：触发新部署
   git commit --allow-empty -m "触发重新部署"
   git push
   ```

3. **验证环境变量**

   重新部署后，访问：
   ```
   https://你的域名/api/debug/check-monitor-setup
   ```

   确认所有环境变量显示为 `true`

### 问题 2: 授权条件判断失败

**症状：**
- 日志显示 `处理授权请求`
- 但没有显示 `进入授权成功处理流程`

**原因：**
- `isAuthorized` 参数为 `false` 或 `undefined`

**调试代码：**

在 `src/app/api/user/authorize/route.ts` 第 377 行附近添加更详细的日志：

```typescript
// 在第 377 行之前添加
console.log('🔍 授权参数详情:')
console.log('  - isAuthorized:', isAuthorized, '(类型:', typeof isAuthorized, ')')
console.log('  - shouldAuthorize:', shouldAuthorize, '(类型:', typeof shouldAuthorize, ')')
console.log('  - 条件结果:', isAuthorized && shouldAuthorize)

if (isAuthorized && shouldAuthorize) {
  // ...
}
```

推送更新后，重新测试授权，查看日志。

### 问题 3: walletMonitorService 初始化失败

**症状：**
- 日志显示 `添加地址到Telegram动账监听系统`
- 但立即显示错误

**可能原因：**
- Supabase 连接失败
- 权限问题

**解决方法：**

1. 检查 `SUPABASE_SERVICE_ROLE_KEY` 是否正确
2. 在 Supabase Dashboard → Settings → API → Project API keys
3. 复制 `service_role` key（不是 `anon` key）
4. 更新 Vercel 环境变量

### 问题 4: Moralis Stream 添加失败

**症状：**
- 日志显示 `添加地址到 Moralis Stream 链上监听`
- 但显示错误 `Stream not found`

**解决方法：**

**方案 A：手动创建 Stream**

1. 访问 https://admin.moralis.io/streams
2. 点击 **"+ New Stream"**
3. 配置：
   ```
   Name: ETH USDT Monitor
   Tag: eth-usdt-monitor
   Blockchain: Ethereum Mainnet
   Webhook URL: https://你的域名/api/moralis/webhook
   
   Contract: 0xdAC17F958D2ee523a2206206994597C13D831ec7
   ABI: [Transfer 事件的 ABI]
   Topic0: Transfer(address,address,uint256)
   ```
4. **不要**手动添加地址（系统会自动添加）
5. 点击 **Save**

**方案 B：使用脚本创建**

```bash
cd ceshi
node recreate-moralis-stream.js
```

### 问题 5: Telegram 通知未发送

**症状：**
- 数据库中 `telegram_notification_queue` 有记录
- 但 `is_sent = false`

**原因：**
- Supabase Edge Function 未部署或未触发

**解决方法：**

1. **部署 Edge Function**

   ```bash
   # 安装 Supabase CLI
   npm install -g supabase

   # 登录
   supabase login

   # 链接项目
   supabase link --project-ref <你的项目ID>

   # 部署函数
   supabase functions deploy telegram-notifier
   ```

2. **配置数据库触发器**

   在 Supabase SQL Editor 运行：

   ```sql
   -- 创建触发器
   CREATE OR REPLACE FUNCTION notify_telegram_on_insert()
   RETURNS TRIGGER AS $$
   BEGIN
     -- 调用 Edge Function
     PERFORM
       net.http_post(
         url:='https://<你的项目>.supabase.co/functions/v1/telegram-notifier',
         headers:=jsonb_build_object('Content-Type','application/json', 'Authorization', 'Bearer ' || current_setting('request.jwt.claim.role')),
         body:=jsonb_build_object('type', 'INSERT', 'table', 'telegram_notification_queue', 'record', to_jsonb(NEW))
       );
     RETURN NEW;
   END;
   $$ LANGUAGE plpgsql;

   -- 删除旧触发器
   DROP TRIGGER IF EXISTS on_notification_insert ON telegram_notification_queue;

   -- 创建新触发器
   CREATE TRIGGER on_notification_insert
     AFTER INSERT ON telegram_notification_queue
     FOR EACH ROW
     EXECUTE FUNCTION notify_telegram_on_insert();
   ```

3. **手动测试 Edge Function**

   ```bash
   curl -X POST \
     'https://<你的项目>.supabase.co/functions/v1/telegram-notifier' \
     -H 'Authorization: Bearer <service_role_key>' \
     -H 'Content-Type: application/json' \
     -d '{
       "type": "INSERT",
       "table": "telegram_notification_queue",
       "record": {
         "id": 1,
         "notification_type": "user_authorize",
         "user_id": "test",
         "is_sent": false
       }
     }'
   ```

## 🚨 紧急修复

如果以上方法都不行，使用这个临时修复脚本：

### 手动添加地址到监听

创建文件 `scripts/manual-add-monitor.js`:

```javascript
const { createClient } = require('@supabase/supabase-js')
const Moralis = require('moralis').default

const SUPABASE_URL = process.env.NEXT_PUBLIC_SUPABASE_URL
const SUPABASE_KEY = process.env.SUPABASE_SERVICE_ROLE_KEY
const MORALIS_API_KEY = process.env.MORALIS_API_KEY

const supabase = createClient(SUPABASE_URL, SUPABASE_KEY)

async function addAddress(address) {
  console.log(`添加地址: ${address}`)
  
  // 1. 查找用户
  const { data: user } = await supabase
    .from('nh_member_new')
    .select('id')
    .eq('wallet_address', address)
    .eq('is_active', true)
    .single()
  
  if (!user) {
    console.error('用户不存在')
    return
  }
  
  // 2. 添加到数据库
  await supabase
    .from('wallet_monitor')
    .upsert({
      member_id: user.id,
      wallet_address: address,
      is_active: true,
      monitor_transactions: true,
      created_at: new Date().toISOString()
    })
  
  console.log('✅ 已添加到数据库')
  
  // 3. 添加到 Moralis
  await Moralis.start({ apiKey: MORALIS_API_KEY })
  
  await Moralis.Streams.addAddress({
    id: 'eth-usdt-monitor',
    address: [address]
  })
  
  console.log('✅ 已添加到 Moralis Stream')
}

// 使用
const address = process.argv[2]
if (!address) {
  console.error('用法: node manual-add-monitor.js 0xYourAddress')
  process.exit(1)
}

addAddress(address).then(() => {
  console.log('完成')
  process.exit(0)
}).catch(err => {
  console.error('失败:', err)
  process.exit(1)
})
```

运行：
```bash
node scripts/manual-add-monitor.js 0xYourAddress
```
