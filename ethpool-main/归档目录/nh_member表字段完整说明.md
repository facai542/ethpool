# nh_member 表字段完整说明

## 📋 表概述
`nh_member` 表是用户主表，存储所有用户的基本信息、资金状态、授权状态等核心数据。

## 🔍 字段详细说明

### **基础信息字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `id` | integer | 主键ID | 用户的唯一标识符 |
| `token` | varchar | 登录token | 用户登录凭证，用于身份验证 |
| `address` | varchar | 钱包地址 | 用户的钱包地址（主要地址） |
| `auth_address` | varchar | 授权平台地址 | 用户授权给平台的地址 |

### **层级关系字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `agent_id` | integer | 代理ID | 用户的代理推荐人ID |
| `pid` | integer | 父级ID | 用户的直接推荐人ID |
| `childs` | integer | 直推用户次数 | 该用户直接推荐的下级用户数量 |

### **邀请系统字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `invite_code` | varchar | 邀请码 | 用户专属的邀请码，用于推荐其他用户 |

### **时间字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `add_time` | timestamp | 创建时间 | 用户注册时间 |
| `update_time` | timestamp | 更新时间 | 用户信息最后更新时间 |
| `pretime` | varchar | 上次登录时间 | 用户最后一次登录时间 |

### **状态字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `status` | smallint | 账号状态 | 1=激活，0=未激活 |
| `is_del` | smallint | 删除标识 | 1=删除，0=正常 |
| `is_effective` | integer | 是否有效客户 | 1=是，0=否 |
| `approved` | integer | 授权平台数 | 授权状态标识 |
| `type` | smallint | 网络类型 | 1=TRC，2=ERC |

### **资金字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `cash` | numeric | 剩余余额 | 用户平台钱包余额（收益ETH或TRX） |
| `usdt` | numeric | 用户鱼苗金额 | 用户质押的USDT金额 |
| `eth` | numeric | ETH余额 | 用户的ETH余额 |
| `withdrawal_usdt` | numeric | 可提现USDT | 用户可以提现的USDT金额 |
| `gj_cash` | numeric | 归集金额数量 | 归集的总金额 |

### **归集系统字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `gj_status` | smallint | 归集状态 | 1=未归集，2=已归集，3=归集中 |

### **提现控制字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `forbid_tx` | smallint | 禁止提现 | 1=是，2=否 |
| `forbid_day` | integer | 禁止提现天数 | 禁止提现的天数限制 |
| `forbid_stime` | timestamp | 禁止开始时间 | 提现禁止的开始时间 |
| `forbid_etime` | timestamp | 禁止结束时间 | 提现禁止的结束时间 |

### **系统控制字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `pause` | smallint | 暂停发息 | 1=是，2=否 |
| `hash` | varchar | 授权哈希值 | 用户授权交易的哈希值 |

### **奖励系统字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `first_authorization_reward` | boolean | 首次授权奖励 | 是否已获得首次授权奖励 |
| `has_received_eth_reward` | boolean | ETH奖励状态 | 是否已赠送首次授权ETH奖励 |

### **其他字段**

| 字段名 | 类型 | 说明 | 业务含义 |
|--------|------|------|----------|
| `ip` | varchar | IP地址 | 用户注册时的IP地址 |
| `user_remark` | text | 用户备注信息 | 用于Telegram通知显示的用户备注 |

## 🎯 业务逻辑关系

### **用户状态流转**：
```
注册 → 激活 → 授权 → 有效客户 → 质押 → 收益 → 提现
```

### **资金流向**：
```
用户钱包 → 授权 → 质押(usdt) → 收益(cash) → 提现(withdrawal_usdt)
```

### **推荐关系**：
```
代理(agent_id) → 用户(pid) → 下级(childs)
```

### **归集流程**：
```
未归集(gj_status=1) → 归集中(gj_status=3) → 已归集(gj_status=2)
```

## 📊 字段使用场景

### **首页账户卡片显示**：
- `usdt` → 已兑换金额
- `cash` → 可提取金额  
- `withdrawal_usdt` → 已提现金额
- `eth` → ETH余额
- `approved` → 授权状态

### **推荐系统**：
- `invite_code` → 生成邀请链接
- `pid` → 推荐关系查询
- `childs` → 推荐统计

### **风控系统**：
- `forbid_tx` → 提现限制
- `forbid_day` → 限制天数
- `pause` → 暂停发息

### **通知系统**：
- `user_remark` → Telegram显示
- `auth_address` → 授权地址通知

## ⚠️ 重要注意事项

1. **字段一致性**：`address` 和 `auth_address` 在大多数情况下相同
2. **资金安全**：`forbid_tx` 系列字段用于风控
3. **状态同步**：`is_effective` 和 `approved` 需要保持同步
4. **时间戳**：所有时间字段使用服务器时区

## 🔧 维护建议

1. **定期备份**：用户数据需要定期备份
2. **状态检查**：定期检查用户状态的一致性
3. **风控监控**：监控异常提现和归集操作
4. **数据清理**：定期清理已删除用户的数据

---

**总结**：`nh_member` 表是整个用户系统的核心，包含了用户从注册到交易的全生命周期数据，需要仔细维护和监控。
