# 数据库字段更新方案

## 📋 当前问题分析

根据您的需求，当前数据库字段映射存在以下问题：

### **当前字段映射问题**：
1. **"已兑换"** 和 **"可提取"** 都使用 `usdt` 字段
2. **"总产出"** 使用 `eth` 字段，但含义不明确
3. **"分红"** 使用 `usdt` 字段计算收益率，逻辑混乱
4. 缺少专门的累计分红收益字段

## 🎯 新字段映射方案

### **您提出的新字段结构**：

| 显示名称 | 数据库字段 | 类型 | 说明 |
|---------|-----------|------|------|
| **用户状态** | `approval_status` | integer | 0=未授权，1=已授权 |
| **总产出** | `total_eth_received` | numeric | 总共获得的ETH（赠送+奖励） |
| **钱包余额** | 链上查询 | - | 通过 useUSDTBalance 获取 |
| **可兑换** | `reward_eth_balance` | numeric | 可用于兑换的ETH余额 |
| **已提取** | `withdrawn_usdt` | numeric | 已提现的USDT金额 |
| **已兑换** | `exchanged_usdt` | numeric | ETH兑换成的USDT总额 |
| **可提取** | `withdrawable_usdt` | numeric | 可提现的USDT余额 |
| **分红** | `total_dividend` | numeric | 累计分红收益 |

## 🔧 数据库更新SQL脚本

### **1. 添加新字段**

```sql
-- 添加新的字段到 nh_member 表
ALTER TABLE nh_member 
ADD COLUMN IF NOT EXISTS approval_status INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS total_eth_received NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS reward_eth_balance NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS withdrawn_usdt NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS exchanged_usdt NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS withdrawable_usdt NUMERIC DEFAULT 0,
ADD COLUMN IF NOT EXISTS total_dividend NUMERIC DEFAULT 0;

-- 添加注释说明
COMMENT ON COLUMN nh_member.approval_status IS '用户授权状态：0=未授权，1=已授权';
COMMENT ON COLUMN nh_member.total_eth_received IS '总共获得的ETH（赠送+奖励）';
COMMENT ON COLUMN nh_member.reward_eth_balance IS '可用于兑换的ETH余额';
COMMENT ON COLUMN nh_member.withdrawn_usdt IS '已提现的USDT金额';
COMMENT ON COLUMN nh_member.exchanged_usdt IS 'ETH兑换成的USDT总额';
COMMENT ON COLUMN nh_member.withdrawable_usdt IS '可提现的USDT余额';
COMMENT ON COLUMN nh_member.total_dividend IS '累计分红收益';
```

### **2. 数据迁移脚本**

```sql
-- 迁移现有数据到新字段
UPDATE nh_member SET
    approval_status = COALESCE(approved, 0),
    total_eth_received = COALESCE(eth, 0),
    reward_eth_balance = COALESCE(eth, 0),
    withdrawn_usdt = COALESCE(withdrawal_usdt, 0),
    exchanged_usdt = COALESCE(usdt, 0),
    withdrawable_usdt = COALESCE(cash, 0),
    total_dividend = COALESCE(gj_cash, 0)
WHERE is_del = 0;
```

| `approval_status` | `approved` | 直接映射 |

| `withdrawn_usdt` | `withdrawal_usdt` | 重命名，含义更明确 |
| `exchanged_usdt` | `usdt` | 重命名，明确为兑换金额 |
| `withdrawable_usdt` | `cash` | 重命名，明确为可提取金额 |
| `total_dividend` | `gj_cash` | 重命名，明确为分红收益 |

## 🔄 业务逻辑更新

### **数据更新流程**：

1. **用户授权时**：
   ```sql
   UPDATE nh_member SET approval_status = 1 WHERE id = ?;
   ```

2. **发放ETH奖励时**：
   ```sql
   UPDATE nh_member SET 
       total_eth_received = total_eth_received + ?,
       reward_eth_balance = reward_eth_balance + ?
   WHERE id = ?;
   ```

3. **ETH兑换USDT时**：
   ```sql
   UPDATE nh_member SET 
       reward_eth_balance = reward_eth_balance - ?,
       exchanged_usdt = exchanged_usdt + ?,
       withdrawable_usdt = withdrawable_usdt + ?
   WHERE id = ?;
   ```

4. **用户提现时**：
   ```sql
   UPDATE nh_member SET 
       withdrawable_usdt = withdrawable_usdt - ?,
       withdrawn_usdt = withdrawn_usdt + ?
   WHERE id = ?;
   ```
