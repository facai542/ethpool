# 手动发送奖励系统文档

## 概述

本系统为管理后台提供了手动发送奖励的功能，支持一键查询所有授权地址的链上USDT余额，并根据真实余额一键发送奖励。同时支持管理员自定义给每个用户增加或减少奖励ETH。

## 功能特性

### 1. 一键查询链上余额
- **功能**: 批量查询所有授权用户的链上USDT余额
- **API**: `/api/admin/get-all-user-balances`
- **特点**: 
  - 实时获取链上余额，确保数据准确性
  - 支持批量查询，提高效率
  - 显示查询成功/失败状态

### 2. 一键发送奖励
- **功能**: 根据用户链上USDT余额自动计算并发送奖励
- **API**: `/api/admin/manual-send-rewards`
- **特点**:
  - 支持多用户批量选择
  - 基于真实链上余额计算奖励
  - 不受时间次数限制，可随时手动发送

### 3. 自定义奖励调整
- **功能**: 管理员可以自定义给每个用户增加或减少奖励ETH
- **特点**:
  - 支持增加/减少两种操作
  - 需要填写调整原因
  - 实时更新用户ETH余额

## 技术实现

### 1. API端点

#### 获取所有用户链上余额
```typescript
GET /api/admin/get-all-user-balances
```
**功能**: 批量获取所有授权用户的链上USDT余额
**返回**: 用户列表、链上余额、查询状态

#### 手动发送奖励
```typescript
POST /api/admin/manual-send-rewards
```
**请求体**:
```json
{
  "userIds": [1, 2, 3],
  "customRewards": [
    {
      "userId": 1,
      "ethAmount": 0.001,
      "type": "add",
      "reason": "管理员手动调整"
    }
  ]
}
```

### 2. 数据库操作

#### 更新用户ETH余额
```sql
UPDATE nh_member 
SET eth = COALESCE(eth, 0) + reward_eth
WHERE id = user_id
```

#### 记录奖励发放
```sql
INSERT INTO finance_orders (
  user_id, order_no, method_id, type, amount, actual_amount,
  status, remark, create_time, update_time
) VALUES (
  user_id, 'MANUAL_userId_timestamp', 1, 'withdraw', reward_eth, reward_eth,
  1, '[手动奖励] 详细信息', unix_timestamp, unix_timestamp
)
```

## 使用说明

### 1. 访问页面
- **路径**: `/admin/manual-rewards`
- **权限**: 管理员和代理用户
- **菜单位置**: 用户管理 → 手动发送奖励

### 2. 操作流程

#### 步骤1: 查询链上余额
1. 点击"一键查询所有授权地址链上USDT余额"按钮
2. 系统会批量查询所有有效用户的链上USDT余额
3. 查看查询结果，确认用户余额状态

#### 步骤2: 选择用户
1. 在用户列表中选择要发送奖励的用户
2. 支持全选/取消全选功能
3. 可以单独为每个用户设置自定义奖励

#### 步骤3: 设置自定义奖励（可选）
1. 点击用户行的"调整奖励"按钮
2. 在弹出的模态框中设置：
   - 调整类型：增加/减少
   - ETH数量：具体数量
   - 调整原因：必填
3. 保存设置

#### 步骤4: 发送奖励
1. 点击"一键发送奖励"按钮
2. 系统会根据设置发送奖励
3. 查看执行结果

### 3. 界面说明

#### 操作面板
- **查询按钮**: 一键查询所有用户链上余额
- **发送按钮**: 一键发送奖励（显示选中用户数量）
- **全选按钮**: 全选/取消全选所有用户

#### 用户列表
- **选择框**: 多选用户
- **用户信息**: ID、地址、余额信息
- **奖励信息**: 自动计算奖励、自定义奖励
- **操作按钮**: 调整奖励、设置自定义

#### 自定义奖励模态框
- **用户信息**: 显示用户地址和当前ETH余额
- **调整类型**: 增加/减少选择
- **ETH数量**: 数值输入
- **调整原因**: 文本输入（必填）

## 奖励计算规则

### 1. 自动计算奖励
基于用户链上USDT余额，按照以下等级计算：
- 1-4,999 USDT: 2% (单次0.5%)
- 5,000-9,999 USDT: 2.5% (单次0.625%)
- 10,000-99,999 USDT: 3% (单次0.75%)
- 100,000-199,999 USDT: 4% (单次1%)
- 200,000+ USDT: 5% (单次1.25%)

### 2. 自定义奖励
- 管理员可以手动设置任意数量的ETH奖励
- 支持增加和减少两种操作
- 需要填写调整原因
