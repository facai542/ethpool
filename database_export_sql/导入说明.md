# Supabase 数据库导入说明

## 📁 文件位置

**主要导入文件**: `20251220_021043/all_tables_data.sql`

这个文件包含了所有 107 个表的数据，可以直接导入到 Supabase。

## 🚀 快速导入（推荐方法）

### 方法 1: 使用 Supabase Dashboard SQL Editor

1. **登录 Supabase**
   - 访问 https://app.supabase.com
   - 选择你的目标项目

2. **打开 SQL Editor**
   - 左侧菜单 → "SQL Editor"
   - 点击 "New query"

3. **导入数据**
   - 打开文件 `20251220_021043/all_tables_data.sql`
   - 复制**全部内容**（Ctrl+A, Ctrl+C）
   - 粘贴到 SQL Editor（Ctrl+V）
   - 点击 "Run" 按钮或按 `Ctrl+Enter`

4. **等待完成**
   - 文件大小约 6.5 MB，包含 33,632 条记录
   - 执行时间通常为 1-5 分钟
   - 查看底部结果面板确认成功

### 方法 2: 使用命令行（psql）

如果你有数据库连接信息：

```bash
# Windows PowerShell
psql -h db.你的项目ID.supabase.co -U postgres -d postgres -f "20251220_021043\all_tables_data.sql"

# Linux/Mac
psql -h db.你的项目ID.supabase.co -U postgres -d postgres -f 20251220_021043/all_tables_data.sql
```

**获取连接信息**:
- Supabase Dashboard → Settings → Database → Connection string

## ✅ 验证导入

导入完成后，在 SQL Editor 中执行：

```sql
-- 检查表数量（应该是 107）
SELECT COUNT(*) as 表数量 
FROM information_schema.tables 
WHERE table_schema = 'public' 
  AND table_type = 'BASE TABLE';

-- 检查主要表的记录数
SELECT 'nh_member_new' as 表名, COUNT(*) as 记录数 FROM nh_member_new
UNION ALL
SELECT 'users', COUNT(*) FROM users
UNION ALL
SELECT 'wallet_balances', COUNT(*) FROM wallet_balances;
```

## ⚠️ 重要提示

1. **数据安全**
   - SQL 文件使用 `ON CONFLICT DO NOTHING`
   - 如果记录已存在，**不会覆盖**，会跳过
   - 所有操作在事务中，出错会自动回滚

2. **文件大小**
   - 如果 SQL Editor 提示文件太大
   - 使用命令行方法（psql）导入
   - 或分批导入单独的表文件

3. **权限要求**
   - 需要项目所有者或协作者权限
   - 或使用数据库密码（Service Role Key）

## 🔧 故障排除

### 问题：导入失败，提示权限不足
**解决**: 确保使用正确的数据库密码或 Service Role Key

### 问题：文件太大无法导入
**解决**: 
- 使用命令行工具（psql）
- 或分批导入单独的表文件（在 `20251220_021043/` 目录下）

### 问题：外键约束错误
**解决**: 
- 检查表之间的依赖关系
- 确保按正确顺序导入
- 或暂时禁用外键检查（不推荐）
