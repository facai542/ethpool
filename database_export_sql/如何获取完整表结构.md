# 如何获取完整的表结构（CREATE TABLE 语句）

## 🎯 目标
生成一个只包含表结构（CREATE TABLE），不包含数据的 SQL 文件。

## ✅ 推荐方法：使用 pg_dump

这是最准确、最简单的方法：

### 步骤 1: 安装 PostgreSQL 客户端

**Windows:**
```powershell
# 使用 Chocolatey
choco install postgresql

# 或下载安装包
# https://www.postgresql.org/download/windows/
```

**Mac:**
```bash
brew install postgresql
```

**Linux:**
```bash
sudo apt-get install postgresql-client
```

### 步骤 2: 获取数据库连接信息

1. 登录源数据库 Supabase Dashboard: https://bfcpimnfgidhgigtgehs.supabase.co
2. 进入 **Settings** → **Database**
3. 复制 **Connection string**（使用 Session mode）
4. 或记录以下信息：
   - Host: `db.bfcpimnfgidhgigtgehs.supabase.co`
   - Database: `postgres`
   - User: `postgres`
   - Password: （在 Dashboard 中获取）

### 步骤 3: 导出表结构

**Windows PowerShell:**
```powershell
pg_dump -h db.bfcpimnfgidhgigtgehs.supabase.co `
        -U postgres `
        -d postgres `
        --schema-only `
        --no-owner `
        --no-privileges `
        -t 'public.*' `
        > database_export_sql/create_all_tables.sql
```

**Linux/Mac:**
```bash
pg_dump -h db.bfcpimnfgidhgigtgehs.supabase.co \
        -U postgres \
        -d postgres \
        --schema-only \
        --no-owner \
        --no-privileges \
        -t 'public.*' \
        > database_export_sql/create_all_tables.sql
```

### 参数说明
- `--schema-only`: 只导出表结构，不导出数据 ✅
- `--no-owner`: 不包含所有者信息
- `--no-privileges`: 不包含权限信息
- `-t 'public.*'`: 只导出 public schema 下的所有表

### 步骤 4: 输入密码
执行命令后会提示输入密码，在 Supabase Dashboard → Settings → Database 中获取。

## 🔄 方法 2: 使用 Supabase SQL Editor

1. 登录源数据库 Supabase Dashboard
2. 打开 **SQL Editor**
3. 执行以下查询获取表结构（见 `get_table_schema.sql` 文件）
4. 根据查询结果手动生成 CREATE TABLE 语句

## 🤖 方法 3: 从单独的表文件提取

每个表都有单独的 SQL 文件（在 `20251220_021043/` 目录下），你可以：

1. 打开每个表的 SQL 文件
2. 查看 INSERT 语句中的列定义
3. 手动创建 CREATE TABLE 语句

例如，从 `nh_member_new.sql` 的 INSERT 语句：
```sql
INSERT INTO nh_member_new (id, wallet_address, approved, ...) VALUES ...
```

可以推断出表结构：
```sql
CREATE TABLE nh_member_new (
    id UUID,
    wallet_address TEXT,
    approved INTEGER,
    ...
);
```

## 📝 方法 4: 使用 Supabase CLI

```bash
# 安装
npm install -g supabase

# 登录
supabase login

# 链接项目
supabase link --project-ref bfcpimnfgidhgigtgehs

# 导出表结构
supabase db dump --schema-only > database_export_sql/create_all_tables.sql
```

## ⚠️ 重要提示

1. **数据类型推断**: 如果从 INSERT 语句推断，数据类型可能不准确
2. **约束缺失**: 推断的方法不会包含外键、索引等约束
3. **推荐使用 pg_dump**: 这是最准确的方法，包含所有约束和索引
