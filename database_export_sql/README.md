# 数据库导出文件

本目录包含可以直接导入 Supabase 的数据库文件。

## 📂 目录结构

```
database_export_sql/
├── 20251220_021043/          # 最新导出（推荐使用）
│   ├── all_tables_data.sql   # ⭐ 所有表的合并文件（直接导入这个）
│   ├── *.sql                 # 单独的表文件
│   └── export_summary.json   # 导出摘要信息
├── 导入说明.md              # 中文快速导入指南
└── SUPABASE_IMPORT_GUIDE.md # 详细导入文档（英文）
```

## 🎯 快速开始

### 最简单的方法

1. 打开 `20251220_021043/all_tables_data.sql`
2. 复制全部内容
3. 在 Supabase Dashboard → SQL Editor 中粘贴并执行

**就这么简单！** ✅

## 📋 文件说明

### `all_tables_data.sql` ⭐
- **用途**: 包含所有 107 个表的数据
- **大小**: 约 6.5 MB
- **记录数**: 33,632 条
- **格式**: 已优化，可直接导入 Supabase
- **特性**: 
  - 使用事务（BEGIN/COMMIT）
  - 使用 ON CONFLICT DO NOTHING（不覆盖现有数据）

### 单独表文件

- 可以单独导入某个表
- 格式与合并文件相同
